# AI-Powered Aviation Safety Prediction System

## Overview

An educational machine learning project that predicts flight safety
categories from flight parameters using a Random Forest classifier.

## Features

- Flight parameter input
- Safe / Unsafe classification
- Probability display
- Interactive dashboard
- Machine learning model evaluation
- Synthetic dataset generation

## Input Parameters

- Altitude
- Airspeed
- Vertical speed
- Pitch angle
- Visibility
- Temperature

## Technologies

Python, Pandas, NumPy, Scikit-learn, Streamlit

## Algorithm

Random Forest Classifier

## Dataset

Synthetic dataset created for academic demonstration purposes.

## Disclaimer

This project is a learning prototype. It is not a real aviation
safety system and is not validated for real-world flight decisions.
